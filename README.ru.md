# Frame Studio — руководство

Исходный код V4 для одной погодной фоторамки Good Display GDEP133C02: FastAPI/PostgreSQL, React, ESP32-S3/ESP-IDF, 1600×1200 логических пикселей. Базис c71b51f: сумерки фиксированы 60 минутами, Astral не добавлен. Имена пакета и команд сохранены: `eink-weather-frame`, `eink_frame`, `eink-weather-scheduler`, `eink-home-render-worker`, `eink-spark-worker`.

Ручной режим без GPU: загрузка изображения, настройка яркости, контраста, насыщенности, гаммы, резкости, дизеринга и его силы; черновик и превью; публикация. Оригинал `source.png` и результаты неизменяемы: History позволяет повторную обработку оригинала и публикацию сохранённого кадра. Для отдельной конвертации PostgreSQL не требуется; публикация, история в БД, пресеты, расписания и текущее состояние устройства требуют БД. Команды быстрой проверки, запуска и схема API — в [README.md](README.md) и [docs/backend.md](docs/backend.md).

Автоматический режим: планировщик → Open-Meteo → снимки погоды и промпта → задания PostgreSQL → отдельный GPU-worker с ComfyUI → локальный render-worker → манифест устройства. По умолчанию граф Qwen-Image-2512; FLUX.2 Klein 4B и Z-Image Turbo — дополнительные пути кода, веса/узлы должны быть установлены отдельно. GPU worker может запускать и останавливать заранее подготовленный контейнер либо пользоваться постоянно работающим ComfyUI. Микроконтроллер проверяет загружаемый кадр, готовит его на SD, обновляет дисплей, сообщает состояние/подтверждение, сохраняет последний исправный кадр.

Навигация: [архитектура](docs/architecture.md), [цветовой тракт](docs/color-pipeline.md), [развёртывание, установка моделей, резервное копирование и восстановление](deploy/README.md), [прошивка, сборка ESP-IDF и пины](docs/firmware.md), [происхождение компонентов и права](THIRD_PARTY_NOTICES.md). В дереве нет фотографий, весов моделей и готовых бинарников.

Ограничения: одна рамка; отсутствует проверка смыслового соответствия картинки ночной погоде; API оператора/UI без пользовательской аутентификации, HTTP устройства без TLS — только изолированная частная сеть/VPN. SoftAP с паролем от MAC не является надёжным секретом. Подписанный OTA, глубокий сон, DS18B20 не реализованы; схема factory-разделов без OTA-слотов. Корневая MIT-лицензия распространяется только на самостоятельно созданный код проекта и не лицензирует включённые команды/данные драйвера Good Display. Условия распространения производных от образца драйверов в изученном материале не установлены: явное разрешение владельца включить файлы не равнозначно разрешению вендора на перераспространение. См. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Полная прошивка ESP32-S3 собрана с ESP-IDF v5.5.5; повторной прошивки платы и аппаратных испытаний не проводилось. Результаты локальных проверок — в [docs/verification.md](docs/verification.md), текущий CI — по значку в README.
